- Forka detta repo och sedan skapa varsin branch (elev_1, elev_2 och eventuellt elev_3) och
- Var för sig hitta code smells eller andra refaktoreringsmöjligheter i minst två filer på egen hand.

- Granska varandras kod som om ni *inte* hade en egen branch med liknande rättelser och börja sedan med att merga elev_1's branch.
- Fortsätt sedan med elev_ (och elev_3 om nödvändigt) och lös kodkonflikter som eventuellt uppstår.
